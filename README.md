> **End-to-end data engineering + analytics solution** built to process large-scale e-commerce data and generate actionable business insights. The pipeline processes **~7.5 million+ rows** to simulate real-world production-scale workloads.

### ⚡ Key Features

<details open>
<summary><b>🔹 Parallel Data Fetching</b></summary>

```python
from concurrent.futures import ProcessPoolExecutor

with ProcessPoolExecutor() as executor:
    futures = {executor.submit(fetch_table, table): table
               for table in TABLES}
# Fetches multiple tables simultaneously
# Optimized to avoid DB overload
```
</details>

<details>
<summary><b>🔹 Chunk-Based Processing (500K rows/chunk)</b></summary>

```python
for chunk in pd.read_sql(query, engine, chunksize=500_000):
    cleaned = clean_dataframe(chunk)
    chunks.append(cleaned)
# Prevents memory overflow on 7.5M+ row datasets
```
</details>

<details>
<summary><b>🔹 Automated Data Cleaning Engine</b></summary>

| Step | Action |
|------|--------|
| Missing Values | Smart fill / drop based on column type |
| Dtype Downcast | `int64 → int32`, `float64 → float32` |
| String Standardization | `.strip().title()` on all categoricals |
| Datetime Fixing | Coerce invalid → NaT, extract features |

</details>

<details>
<summary><b>🔹 Table-Specific Transformations</b></summary>

| Table | Transformation |
|-------|----------------|
| **Customers** | Email validation · Duplicate removal · Multi-index |
| **Orders** | Status normalization · Date feature extraction (year/month) |
| **Order Items** | IQR-based outlier handling |
| **Payments** | Digital classification · Amount outlier clipping |
| **Products** | Category standardization · `total_price` derived metric |

</details>

<details>
<summary><b>🔹 Optimized Parquet Storage</b></summary>

```python
df.to_parquet(
    path     = "parquet_files/orders.parquet",
    engine   = "pyarrow",
    compression = "snappy",   # ↓ ~60% file size
    index    = False
)
```
</details>

### ▶️ How to Run

```bash
# 1. Clone the repository
git clone https://github.com/Karan7088/Ecommerce_Analytics_Project.git
cd Ecommerce_Analytics_Project

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure environment
cp .env.example .env
# Edit .env with your MySQL credentials

# 4. Run the ETL pipeline
python scripts/pipeline.py

# 5. Open the BI Dashboard
# Load dashboard/dashboard.pbix in Power BI Desktop
```

```env
# .env configuration
DB_HOST=localhost
DB_PORT=3306
DB_USER=your_username
DB_PASSWORD=your_password
CUSTOMERS_DB=customers_db
ECOMMERCE_DB=ecommerce_db
```
